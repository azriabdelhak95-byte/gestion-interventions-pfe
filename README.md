# Projet de Fin d'Études - AZ Engineering

Application de gestion d'interventions techniques (Backend Node.js & Mobile React Native).

## Instructions de lancement :

1. **Backend** : Ouvrir le terminal dans `backend-interventions/backend`, taper `npm install`, puis `node server.js`
2. **Mobile** : Ouvrir le terminal dans `mobile-interventions`, taper `npm install`, puis `npx expo start`
